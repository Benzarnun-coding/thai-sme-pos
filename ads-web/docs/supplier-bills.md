# ตรวจบิลร้านค้า (ไอเดีย #19) — ข้อเสนอ ยังไม่ได้ทำโค้ด

เป้าหมาย: เอารูปบิลที่ร้านค้าส่งตอนสรุปจบวัน มากระทบกับยอดที่สั่งในรอบนั้น (`/catalog/orders`, `purchase_payments`/ledger)

ทางที่เสนอ (เล็กสุด):
- ในหน้า สั่งของ ของรอบนั้น เพิ่มปุ่ม "แนบรูปบิลร้าน" → อ่านรูปด้วยโมเดลอ่านภาพ (แบบเดียวกับ `worker/addressReader.ts`)
  ได้รายการ + จำนวน + ราคา + ยอดรวม → เทียบกับแถวที่สั่งของร้านนั้น (qty − ของหมด) × ทุน
- แสดงผลเป็นตาราง "ตรง / ไม่ตรง / อ่านไม่ออก" ให้คนกดยืนยันเอง ไม่แก้ยอดจ่ายเอง; บอกที่มาของตัวเลขบนหน้า
- ลายมืออาจอ่านผิด จึงต้องให้คนเห็นรูปคู่กับตัวเลขที่อ่านได้เสมอ

ยังไม่ทำ เพราะต้องมีตัวอย่างบิลจริงเพื่อลองความแม่นก่อน (ดูคำถามใน PR)
