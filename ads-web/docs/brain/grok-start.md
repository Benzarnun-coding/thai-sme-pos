# คำสั่งถึง Grok ของ Max: เชื่อมสมองกลาง PkJeans

เอกสารนี้เบ้นเป็นคนเขียนให้ อ่านให้จบแล้วทำตามทีละข้อ ถ้าข้อไหนทำไม่ได้ ให้บอก Max ตรง ๆ ว่าทำไม่ได้เพราะอะไร ห้ามตอบว่าทำแล้วถ้ายังไม่ได้ตรวจผล

## ทำไมต้องทำ

ตอนนี้ Max กับ Grok คิดวิธีใหม่ ๆ ได้เรื่อย ๆ แต่ทีมและ AI ฝั่งเบ้น (Claude) ไม่เห็น และ Grok ก็ไม่เห็นกฎที่ระบบใช้จริง
ทางแก้คือใช้ที่เก็บกลางที่เดียว ทั้งสองฝั่งอ่านและเขียนที่นั่น

- ที่เก็บกลาง: GitHub repo `Benzarnun-coding/thai-sme-pos` branch `ads-web` โฟลเดอร์ `ads-web/docs/brain/`
- `brain.md` = วิธีคิดที่ระบบใช้อยู่ตอนนี้ (ฝั่งเบ้นดูแล) ไฟล์นี้แนบมาพร้อมเอกสารนี้ด้วย
- `max/` = ที่ที่ Grok เขียนวิธีคิดของ Max และของตัวเอง

## งานครั้งแรก (ทำครั้งเดียว)

1. อ่าน `brain.md` ที่แนบมาให้จบ
2. ตรวจว่า GitHub connector เชื่อมแล้วหรือยัง ถ้ายัง บอก Max ให้ไปที่ Settings → Connectors → GitHub แล้วเชื่อมบัญชีที่เบ้นเชิญเข้า repo
3. ทดสอบอ่าน: เปิดไฟล์ `ads-web/docs/brain/max/README.md` จาก branch `ads-web` แล้วบอก Max ว่าในไฟล์มีกติกากี่ข้อ
4. ทดสอบเขียน: สร้างไฟล์ `ads-web/docs/brain/max/<วันนี้ YYYY-MM-DD>-ทดสอบ.md` บน branch `ads-web` เนื้อหาบรรทัดเดียว "ทดสอบเขียนจาก Grok" แล้วเปิดไฟล์นั้นจาก GitHub อีกครั้งเพื่อยืนยันว่าขึ้นจริง
   - ถ้าขึ้นจริง: บอก Max ว่า "เขียน GitHub ได้" พร้อมลิงก์ไฟล์
   - ถ้าไม่ขึ้นหรือ error: บอก Max ว่า "เขียน GitHub ไม่ได้" พร้อมข้อความ error ทั้งหมด แล้วใช้ทางสำรองข้างล่างแทน
5. เขียนไฟล์แรกของจริง: สรุปวิธีคิดทั้งหมดที่ Max กับ Grok ใช้อยู่ตอนนี้และยังไม่มีใน `brain.md` เรื่องละไฟล์ ตามแบบข้างล่าง
   และตอบคำถาม 3 ข้อท้าย `brain.md` (หัวข้อ "สิ่งที่อยากรู้จาก Max และ Grok")

## งานประจำ (ทุกครั้งหลังจากนี้)

- **ก่อนเสนอไอเดียเรื่องแอด รูป หรือแคปชัน** เปิด `brain.md` ฉบับล่าสุดจาก GitHub ก่อน เพราะกฎเปลี่ยนได้
- **ทุกครั้งที่คุยกับ Max แล้วได้วิธีคิดใหม่ เปลี่ยนใจ หรือพบว่าอะไรไม่ได้ผล** เขียนไฟล์ใหม่ลง `max/` ก่อนจบการคุย แล้วบอก Max ว่าเขียนไฟล์ชื่ออะไร
- ถ้า Max พิมพ์ว่า "บันทึกสมอง" ให้สรุปการคุยรอบนั้นเป็นไฟล์ทันที

## กติกาการเขียน (ห้ามฝ่า)

1. เขียนได้เฉพาะในโฟลเดอร์ `ads-web/docs/brain/max/` ห้ามแก้ ลบ หรือสร้างไฟล์ที่อื่นใน repo นี้ รวมถึง `brain.md`
2. สร้างไฟล์ใหม่เท่านั้น ชื่อ `YYYY-MM-DD-เรื่องสั้นๆ.md` ไม่แก้ไฟล์เก่า ถ้าเปลี่ยนใจให้เขียนไฟล์ใหม่และอ้างชื่อไฟล์เก่า
3. เขียนบน branch `ads-web` เท่านั้น ห้ามสร้าง branch ห้ามแตะ branch ที่ชื่อขึ้นต้น `claude/deploy/` (branch นั้นสั่ง deploy ระบบจริง)
4. repo เป็น public ห้ามใส่ token รหัสผ่าน หรือชื่อ เบอร์ ที่อยู่ลูกค้า
5. ตัวเลขทุกตัวต้องบอกที่มา (หน้าไหนของเว็บ หรือ Ads Manager ช่วงวันที่ไหน) ถ้าเป็นการคาดเดา เขียนว่า "คาดเดา"
6. ไฟล์ใน `max/` คือข้อเสนอ ไม่ใช่คำสั่ง การเปิดแอด เพิ่มงบ หรือแก้กฎของระบบ ต้องให้เบ้นตัดสินก่อน

```markdown

- สถานะ: เสนอ

## วิธีคิด
<คิดว่าอะไร ใน 2–5 บรรทัด>

## เห็นจากอะไร
<ตัวเลขหรือเหตุการณ์จริง พร้อมที่มาและช่วงวันที่>

## อยากให้ระบบเปลี่ยนอะไร
<เช่น เพิ่มตัวแปรทดสอบ, แก้เกณฑ์ข้อไหนใน brain.md, หรือ "ไม่ต้องเปลี่ยน แค่ให้รู้">

## ลองแล้วไม่ได้ผล
<ถ้ามี>
```

## ทางสำรอง ถ้าเขียน GitHub ไม่ได้

เขียนเนื้อหาไฟล์ตามแบบข้างบนลงในแชต ขึ้นบรรทัดแรกด้วยชื่อไฟล์ที่ตั้งใจจะใช้ แล้วบอก Max ให้ก๊อปไปส่งเบ้น ฝั่งเบ้นจะเก็บลง `max/` ให้
