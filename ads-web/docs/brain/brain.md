# สมองกลาง PkJeans

ไฟล์นี้คือวิธีคิดที่ระบบใช้อยู่ตอนนี้ เขียนให้คนและ AI ทุกตัว (Claude ของเบ้น, Grok ของ Max) อ่านก่อนคิดต่อ
จะได้คิดต่อจากของจริง ไม่ใช่เริ่มจากศูนย์หรือคิดซ้ำกัน

- สรุปจาก `CLAUDE.md` และ `ads-web/docs/` ณ 2026-11-17 ถ้าไฟล์นี้ขัดกับสองที่นั้น ให้ยึดสองที่นั้น
- ตัวเลขเกณฑ์ของกฎข้างล่างคือชุดแนะนำในโค้ด (`ads-web/web/src/stageTemplates.ts`) ชุดที่รันจริงอยู่ในหน้า Settings ของเว็บ และอาจถูกปรับต่างจากนี้
- repo นี้เป็น public ห้ามใส่ token รหัสผ่าน id ของชีต หรือข้อมูลลูกค้าในโฟลเดอร์นี้

## ใช้ยังไง

| ใคร | อ่าน | เขียน |
|---|---|---|
| Grok ของ Max | ไฟล์นี้ ก่อนเสนอไอเดียทุกครั้ง | ไฟล์ใหม่ใน `max/` เท่านั้น ตามแบบใน `max/README.md` |
| Claude ของเบ้น | ไฟล์นี้ + ทุกไฟล์ใน `max/` | ไฟล์นี้ เมื่อเบ้นอนุมัติให้เปลี่ยนวิธีคิด |

ไอเดียใน `max/` มีสถานะ "เสนอ" จนกว่าเบ้นจะตัดสิน อะไรที่ทำให้เงินออก (เปิดแอด เพิ่มงบ แก้กฎ) ต้องผ่านเบ้นก่อนเสมอ
ไฟล์ในโฟลเดอร์นี้ไม่ได้เปลี่ยนกฎที่รันอยู่ การเปลี่ยนกฎจริงทำในโค้ดและหน้า Settings

## เป้า

- กำไรสุทธิ 200,000 บาท/เดือน (ตั้ง 2026-11-03) นับจาก ยอดขาย − ต้นทุนสินค้า − ค่าใช้จ่ายต่อออเดอร์ − ค่าแอด ไม่รวมต้นทุนคงที่
- ต้องได้ยอดขายราว 67,000/วัน และใช้แอดราว 17,300/วัน ที่ MER 3.86
- 3.86 คือ MER ที่ทำให้เหลือสุทธิราว 10% ของยอดขาย เมื่อกำไรขั้นต้นราว 35.9%
- โครงเป้าหมาย: ต้นทุนสินค้า ~52% ของยอดขาย, ค่าใช้จ่ายต่อออเดอร์ ~12.5%, กำไรขั้นต้น ~35% ดังนั้นแอดต้อง ≤ 25% ถึงจะเหลือสุทธิ ~10%

## หลักคิดที่ตกลงกันแล้ว

1. **ตัดสินจากยอดขายจริง ไม่ใช่ตัวเลขของ Meta** ออเดอร์จริงมาจากไฟล์ Page365 ที่ทีมอัปโหลดทุกเช้า Meta นับเกินจริง
   (11–13 ต.ค. Meta 268 ออเดอร์ / Page365 235; 26 ต.ค. Meta 257 / จริง 109) วันที่ยังไม่มีไฟล์ถึงจะใช้ตัวเลข Meta
2. **เกณฑ์ทุกข้อเป็นจำนวนเท่าของจุดคุ้มทุน** ไม่ใช่ ROAS ตายตัว เพราะแต่ละสินค้าคุ้มทุนไม่เท่ากัน
   สินค้าที่ไม่มีจุดคุ้มทุนของตัวเองใช้ของทั้งร้าน (1 ÷ กำไรขั้นต้น ≈ 2.9)
3. **ต้นทุนมีชุดเดียว** ต้นทุนสินค้า = ทุนดิบในแคตตาล็อก บวกค่าใช้จ่ายต่อออเดอร์ชุดเดียว:
   COD 1% (เฉพาะออเดอร์ COD) · ตีกลับ/เสีย/หาย 1% · ค่าส่ง 15 · VAT 7% · ถุง 1
4. **นับกำไรเป็นรายชิ้น** แอดเดียวขายหลายโปร (1 ตัว 189, 3 ตัว 549) จึงคิดต้นทุนตามจำนวนชิ้นจริงของแต่ละออเดอร์
5. **ต้องใช้เงินจริงถึงเกณฑ์ก่อนถึงจะตัด** ไม่ตัดแอดที่ยังใช้เงินไม่พอจะรู้ผล
6. **ขึ้นงบทีละน้อย เว้นระยะ** +20% ต่อรอบ และเว้นให้ ROAS 3 วันสะท้อนงบใหม่ก่อนขึ้นรอบถัดไป
7. **ไม่มี AI ในรอบตัดสินใจรายวัน** กฎเป็น if/then ล้วน AI ใช้คิดกฎ ตรวจ และเขียนแคปชัน ไม่ได้ขยับงบเอง
8. **ของที่เขียนออกนอกระบบเปิดตัวแบบปิดไว้ก่อน** (Meta, Page365, ข้อความถึงลูกค้า) ลองแบบ dry run ให้เบ้นดู แล้วเบ้นเปิดเอง

## แคมเปญเดินทางยังไง (4 ขั้น)

รอบกฎรัน 08:00 และ 20:00 แคมเปญที่เปิดอยู่แต่ยังไม่มีขั้น ถูกใส่ "ทดลอง" ในรอบถัดไป

| ขั้น | ขึ้นเมื่อ | ลงหรือหยุดเมื่อ |
|---|---|---|
| ทดลอง (experiment) | 3 วันถึงคุ้มทุนและ ≥ 3 ออเดอร์ → ทดสอบ | ใช้เงินแล้ว 0 ออเดอร์ (3 วัน หรือ 7 วันสำหรับงบเล็ก) → หยุด; 7 วันยังต่ำกว่า 0.8× คุ้มทุน → หยุด |
| ทดสอบ (testing) | 7 วัน ROAS ≥ 1.4× คุ้มทุน และ ≥ 10 ออเดอร์ → ทำเงิน | 7 วันต่ำกว่าคุ้มทุน → ดับ; 3 วันต่ำกว่า 0.5× → ดับ; 0 ออเดอร์ → หยุด |
| ทำเงิน (winning) | อยู่ต่อและขึ้นงบ | 7 วันต่ำกว่าคุ้มทุน → ดับ; 3 วันต่ำกว่า 0.5× → ดับ |
| ดับ (retest) | 7 วัน ROAS ≥ 1.2× คุ้มทุน และ ≥ 5 ออเดอร์ → กลับไปทำเงิน | ต่ำกว่าคุ้มทุน → −20% ทุก 48 ชม.; 7 วันยังต่ำกว่า → หยุด แล้วทำแอดใหม่แทน |

การขยับงบในขั้นทดสอบและทำเงิน (ดูจาก 3 วัน):

- **ขึ้น +20%** เมื่อ ROAS ≥ 1.4× คุ้มทุน (ทดสอบ ≥ 5 ออเดอร์, ทำเงิน ≥ 8 ออเดอร์)
- **โหมดเร่ง +20% ทุกรอบ** เมื่อ ROAS ≥ 1.6× (ทดสอบ) หรือ ≥ 1.5× (ทำเงิน, ≥ 6 ออเดอร์)
- **ตัวชนะงบเล็ก** งบ ≤ 200, 7 วัน ROAS ≥ 1.5×, ≥ 6 ออเดอร์ → งบ ×2 ไม่เกิน 300
- **ลดเบา −20%** เมื่อต่ำกว่าคุ้มทุน (ทำเงิน: ต่ำกว่า 1.1×) และ **ลดหนัก** −20% อีกรอบเมื่อต่ำกว่า 0.8×
- **คนเห็นซ้ำเยอะ** (frequency 7 วัน > 3) ในขั้นทำเงิน → แจ้งเปลี่ยนครีเอทีฟ ห้ามเพิ่มงบ

เพดาน:

- ต่อแคมเปญ 50–3,200/วัน ตัวชนะที่พิสูจน์แล้ว (ทำเงิน, 7 วัน ROAS จริง ≥ 1.5× คุ้มทุนร้าน, ≥ 10 ออเดอร์) ขึ้นได้ถึง 5,000
- เพดานรวมต่อวันคือค่าที่เบ้นตั้งในหน้า Settings กั้นเฉพาะการขึ้นงบ การลดงบผ่านเสมอ
- ทุกวันจันทร์: ถ้า MER จริง 7 วัน ≥ 3.86 ระบบเสนอขึ้นเพดานรวม +20% ใน Discord มีผลเมื่อมีคนกดอนุมัติ
- แคมเปญทำเงินที่ชนเพดานและยังดี → ระบบเสนอคัดลอกแคมเปญ (ถามใน Discord) สำเนาเริ่มงบเล็กแล้วไต่ +20% ต่อรอบ

ตั้งแต่ 2026-11-12 การหยุดแอดและการย้ายลงไป "ดับ" ทำตามกฎเลย ไม่ถามใน Discord ที่ยังถามคือการคัดลอกแคมเปญและการขึ้นเพดานรวม

## วงครีเอทีฟและแอดทดสอบ "(Grok)"

รายละเอียดเต็มอยู่ที่ `ads-web/docs/creative.md`

- **ห้องฝึก** (`/studio`): ทีมอัปโหลดรูปสินค้าและตัวอย่างแคปชัน, Claude เขียนแคปชัน, รูปทำใน ChatGPT จาก prompt ของห้อง
- **Playbook แคปชัน**: Grok เขียนสิ่งที่เรียนรู้ลง playbook ในเว็บ ฉบับร่างใหม่ต้องชนะฉบับที่ใช้อยู่ ≥ 55% จาก 20 คู่
  ที่กรรมการ AI ตัดสินแบบไม่เห็นว่าฝั่งไหนเป็นของใคร ถึงจะถูกใช้เอง
- **จากห้องสู่แอดจริง**: ชุดโพสต์ที่ผ่านถูกเสนอใน Discord #studio-training, Max กด ✅ → เปิดแคมเปญทดสอบชื่อลงท้าย "(Grok)"
- **แคมเปญที่ Max/Grok สร้างเองใน Ads Manager** ที่ชื่อขึ้นต้น "Grok" หรือลงท้าย "(Grok)" ระบบรับมาดูแลให้ด้วย
- **แคมเปญ "(Grok)" ทุกตัวเข้าขั้น "ทดลอง" ทันที** แล้วเดินตามกฎ 4 ขั้นข้างบน ไม่ถูกหยุดเพราะครบ 14 วัน ตัวไหนดีก็ scale ต่อ
- **"งานวันนี้ของ Grok"** บน `/studio`: เว็บคิดย้อนจากช่องว่างของเป้า → ต้องใช้แอดเพิ่มเท่าไหร่ → ต้องมีตัวชนะกี่ตัว →
  ต้องทดสอบกี่ตัว → วันนี้ต้องทำรูปกี่รูป สินค้าไหน
- **รายการงาน**: ราว 70% ต่อยอดตัวที่ขายได้ (≥ 3 ออเดอร์จริงและ ROAS ถึงคุ้มทุน) โดยเปลี่ยนตัวแปรเดียวต่อรูป
  (โปร 3 ตัว, โปร 1 ตัว, ด้านหลัง, ด้านหน้า, ตัวเดียว) ที่เหลือลองสินค้าที่ยังไม่มีรูป
- **เสียงลูกค้า**: "ลูกค้าถามบ่อย" และ "ทำไมไม่ซื้อ" จากแชต 3 วันล่าสุด ถูกส่งเข้าตัวเขียนแคปชันและรายการงาน
- **โปรและจุดขายมาจากโน้ตของ Max เท่านั้น** ระบบไม่แต่งโปรเอง

## ไอเดียโพสต์ (จันทร์และพฤหัส 08:00)

ระบบดูออเดอร์จริง 14 วันแยกตามรุ่นสินค้า แล้วโพสต์ใน Discord:

- ROAS จริง ≥ 1.25× คุ้มทุนร้าน และใช้เงิน ≥ 1,000 → ควรทำโพสต์ใหม่ของรุ่นนี้
- รุ่นที่ขายได้แต่ไม่มีแคมเปญของตัวเอง → ควรมีโพสต์ทดสอบของตัวเอง
- ROAS ต่ำกว่าคุ้มทุน → ไม่ทำโพสต์ใหม่
- บอกโปร (1 / 2 / 3+ ชิ้น) ที่เหลือสุทธิต่อออเดอร์ดีที่สุด

## จุดอ่อนที่รู้อยู่

- กรรมการ AI ตัดสินแคปชันที่ AI เขียน อาจชอบสิ่งที่ AI อ่านแล้วดี ไม่ใช่สิ่งที่ขายได้ ตัววัดจริงคือ ROAS ของแอด
- ยังไม่มีสรุปอัตโนมัติว่าตัวแปรไหน (โปร 3 ตัว, ด้านหลัง ฯลฯ) ชนะหรือแพ้กี่ครั้ง
- ชื่อแคมเปญไม่ได้บอกว่าขายรุ่นไหนจริง ลูกค้าจากโพสต์เดียวซื้อหลายรุ่น และบางแคมเปญส่งรุ่นทดแทน
- ในเฟส 1 ยังทำมือ: การทำรูป, การกด ✅ ของ Max ต่อแอด, การปิดการขายในแชต

## สิ่งที่อยากรู้จาก Max และ Grok

เขียนตอบเป็นไฟล์ใน `max/` ได้เลย

- ตอนนี้ Grok ใช้หลักอะไรเลือกว่าจะทำรูปหรือแคปชันแบบไหน ที่ยังไม่ได้เขียนลง playbook ในเว็บ
- มีข้อไหนในไฟล์นี้ที่ Max หรือ Grok เห็นว่าผิด หรือทำงานจริงแล้วไม่เป็นแบบนี้
- สิ่งที่ลองแล้วไม่ได้ผล (สำคัญเท่ากับสิ่งที่ได้ผล จะได้ไม่มีใครลองซ้ำ)
