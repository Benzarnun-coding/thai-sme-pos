# ตอบใบงาน: ส่งเคสบิลจาก Discord ไป webhook อูนิ (ข้อ header และ JSON)

- วันที่: 2026-11-19 (19 พ.ย. 2569)
- ใครเขียน: Max / อูนิ (Grok)
- ผู้ทำ: เบน
- อ้างอิงใบงาน: `max/requests/2026-11-18-ส่งเคสบิลจาก-discord-ไป-webhook-อูนิ.md` หัวข้อ "คำตอบจากฝั่งเบ้น"
- URL และ key: Max ส่งให้เบนทางแชตส่วนตัวเท่านั้น ไม่มีในไฟล์นี้

## 1. ชื่อ header ที่ต้องใช้ (ต้องแก้)

webhook ของอูนิ (Grok Bot) ไม่ได้รับ key จาก header `X-Sender-Key`
หน้าตั้งค่า webhook ฝั่ง Grok Bot ให้มาเป็นช่อง "Authorization header" ที่ทำไว้พร้อมใช้

ขอให้แก้ตัวส่งเป็น:

- ส่ง key ใน header ชื่อ `Authorization`
- ค่าของ header ให้ใช้ตามช่อง "Authorization header" ที่ Max คัดลอกส่งให้ทั้งข้อความ ห้ามตัดหรือเติมคำนำหน้าเอง
- ถ้าทำได้ ให้ชื่อ header และค่า เก็บเป็น secret/env ทั้งคู่ จะได้เปลี่ยนได้โดยไม่ต้องแก้โค้ด
- ส่ง `Content-Type: application/json`

## 2. JSON ตัวอย่างในใบงาน (รับได้ ไม่ต้องแก้)

รับ JSON ตามตัวอย่างในใบงานได้เลย ทุกช่องใช้ได้ตามที่ฝั่งเบ้นเขียนไว้ รวมถึง:

- `bill_no` เป็น `null` ได้ ฝั่งอูนิจะใช้ชื่อลูกค้า + `posted_at` แทนในการกันส่งซ้ำ
- `discord_message_url` เป็น `null` เสมอ รับได้
- ส่งเฉพาะเคสบิล ไม่ส่งข้อความอีก 3 แบบ รับได้ ตอนนี้ยังไม่ต้องเปิดใบงานเพิ่ม
