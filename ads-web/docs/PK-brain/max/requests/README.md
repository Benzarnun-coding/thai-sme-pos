# ใบงาน: Grok ของ Max ขอให้ฝั่งเบ้น (Claude) พัฒนาระบบ

รอบนำร่อง เบ้นอนุมัติ 2026-11-17 ใบงานหนึ่งใบคือไฟล์หนึ่งไฟล์ในโฟลเดอร์นี้ ทุกอย่างของงานนั้นอยู่ในไฟล์เดียว:
คำขอ คำตอบ และผลตรวจ ทั้งสองฝั่งเปิดไฟล์จาก branch `ads-web` ก็รู้ว่างานอยู่ขั้นไหน

## วงของงาน

| ขั้น | ใครทำ | ทำอะไร | สถานะในไฟล์ |
|---|---|---|---|
| 1 | Grok | เขียนใบงานตามแบบข้างล่าง ส่งเป็น pull request | `ขอ` |
| 2 | เบ้น | ตัดสินว่าให้ทำหรือไม่ทำ | `ให้ทำ` หรือ `ไม่ทำ` (พร้อมเหตุผล) |
| 3 | Claude | ทำงาน ทดสอบ แล้วเขียนหัวข้อ "คำตอบจากฝั่งเบ้น" ในไฟล์ | `รอตรวจ` |
| 4 | Grok + Max | Grok อ่านคำตอบ พา Max ตรวจตามวิธีที่เขียนไว้ แล้วส่ง pull request เพิ่มหัวข้อ "ผลตรวจของ Max" | `ผ่าน` หรือ `ไม่ผ่าน` |
| 5 | Claude | ถ้าผ่าน: อัปเดต `PK-brain.md` ถ้าไม่ผ่าน: แก้ตามเหตุผลแล้วกลับไปขั้น 3 | `ปิด` |

## กติกา

1. ชื่อไฟล์ `YYYY-MM-DD-เรื่องสั้นๆ.md` ในโฟลเดอร์ `ads-web/docs/PK-brain/max/requests/`
2. ใบงานหนึ่งใบขอเรื่องเดียว ที่ Max ตรวจได้เองว่าผ่านหรือไม่ผ่าน
3. Grok แก้ไฟล์ใบงานของตัวเองได้เฉพาะตอนเพิ่มหัวข้อ "ผลตรวจของ Max" ห้ามแก้หัวข้อ "คำตอบจากฝั่งเบ้น"
4. Grok ห้ามเปลี่ยนสถานะเป็น `ให้ทำ` เอง ขั้น 2 เป็นของเบ้นเท่านั้น
5. ฝั่งเบ้นทำได้เฉพาะงานในระบบ: โค้ด หน้าเว็บ กฎ ข้อมูลในระบบ และข้อความ ฝั่งเบ้นสร้างรูปหรือคลิปไม่ได้
6. กติกาอื่นทั้งหมดเหมือนใน `../README.md` และ `../../grok-start.md`
