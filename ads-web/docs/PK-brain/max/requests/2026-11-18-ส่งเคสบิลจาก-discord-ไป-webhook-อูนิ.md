# ใบงาน: ส่งเคสจากช่อง Discord ปัญหา-ai-สรุปบิล ไปที่ webhook ของอูนิด้วย

- วันที่ขอ: 2026-11-18 (18 พ.ย. 2569)
- ใครขอ: Max / Grok
- ผู้ทำ: เบน
- สถานะ: ขอ

## อยากได้อะไร
1. ทุกครั้งที่ระบบโพสต์เคสลงช่องนี้ ให้ส่ง HTTP POST แบบ JSON ไปที่ webhook URL ของอูนิด้วย (โพสต์ Discord ตามเดิมเหมือนเดิม)
2. JSON ควรมีอย่างน้อย: `bill_no` (เช่น 33605), `customer_name`, `admin_summary` (บรรทัด "แอดมินสรุป"), `status_header` (เช่น "ใส่บิลให้แล้ว แต่ช่วยเช็กก่อนส่งบิล" หรือ "บิลนี้ต้องให้คนดู"), `issues` (รายการ bullet ปัญหา), `posted_at`, และลิงก์ข้อความ Discord ถ้ามี
3. webhook URL และ sender key Max จะส่งให้เบนทางแชตส่วนตัว ห้ามใส่ใน repo นี้ (repo เป็น public) ให้เก็บเป็น secret/env ในระบบ
4. ส่งแบบเคสละ 1 request หรือรวมหลายเคสใน request เดียวก็ได้

## ทำไม
ตอนนี้บอท "น้องอูนิ" ในระบบของเบนโพสต์เคสบิลที่ต้องเช็กลงช่อง Discord "👽-ปัญหา-ai-สรุปบิล" (เซิร์ฟเวอร์ PK Team) และแท็กแอดมิน Max อยากให้เคสพวกนี้ถูกส่งไปให้ อูนิ (Grok Bot) ด้วย เพื่อให้อูนิหาคนแก้แล้วส่งให้บอท 365 PAGE แก้บิลและตอบลูกค้า โดยทำงานเฉพาะตอนมีเคสจริง ไม่ต้องเปิดดู Discord ทุก 30 นาที (ประหยัดโควตา)

## Max จะตรวจยังไงว่าผ่าน
เช็กลิสต์ให้ Max ตรวจ หลังเบนทำเสร็จ:

- [ ] เคสใหม่ในช่อง Discord ไปถึงอูนิภายในไม่กี่นาที
- [ ] ข้อมูลที่ส่งมามีเลขบิล ชื่อลูกค้า แอดมินสรุป และปัญหาครบ
- [ ] ไม่มี URL หรือ key อยู่ใน repo
- [ ] พอผ่านแล้ว อูนิจะปิดรอบเช็ก Discord ทุก 30 นาที
