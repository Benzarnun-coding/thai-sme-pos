# โฟลเดอร์ของ Max และ Grok

ที่เดียวใน repo ที่ Grok ของ Max เขียนได้ ทุกครั้งที่คิดอะไรใหม่ได้ ให้เขียนเป็นไฟล์ใหม่ที่นี่ ทีมจะได้เห็น

## กติกา

1. อ่าน `../PK-brain.md` ก่อนเขียน เพื่อไม่เสนอสิ่งที่ระบบทำอยู่แล้ว
2. สร้างไฟล์ใหม่เท่านั้น ชื่อ `YYYY-MM-DD-เรื่องสั้นๆ.md` เช่น `2026-11-18-รูปด้านหลังขายดีกว่า.md`
3. ห้ามแก้หรือลบไฟล์นอกโฟลเดอร์ `ads-web/docs/PK-brain/max/` ส่งเข้ามาเป็น pull request จาก branch `max-brain/...` เข้า `ads-web` (วิธีอยู่ใน `../grok-start.md`) ฝั่งเบ้นเป็นคน merge
4. ห้ามใส่ token รหัสผ่าน หรือชื่อ เบอร์ ที่อยู่ลูกค้า (repo นี้เป็น public)
5. ตัวเลขทุกตัวต้องบอกที่มา (หน้าไหนของเว็บ ช่วงวันที่ไหน) ถ้าเป็นการคาดเดาให้เขียนว่าคาดเดา

## แบบของไฟล์

```markdown
# <เรื่อง>

- วันที่: YYYY-MM-DD
- ใครคิด: Max / Grok
- สถานะ: เสนอ

## วิธีคิด
<คิดว่าอะไร ใน 2–5 บรรทัด>

## เห็นจากอะไร
<ตัวเลขหรือเหตุการณ์จริง พร้อมที่มาและช่วงวันที่>

## อยากให้ระบบเปลี่ยนอะไร
<เช่น เพิ่มตัวแปรทดสอบ, แก้เกณฑ์ข้อไหนใน PK-brain.md, หรือ "ไม่ต้องเปลี่ยน แค่ให้รู้">

## ลองแล้วไม่ได้ผล
<ถ้ามี>
```

สถานะมี 3 ค่า: `เสนอ` (ค่าเริ่มต้น), `ใช้แล้ว` และ `ไม่ใช้` สองค่าหลังฝั่งเบ้นเป็นคนเปลี่ยนหลังตัดสิน พร้อมเหตุผลหนึ่งบรรทัด
