# PK-brain: สมองกลาง PkJeans

ไฟล์เดียวที่ใช้ตอบว่า "ระบบแอดของ PkJeans คิดยังไง" เขียนให้คนและ AI ทุกตัว (Claude ของเบ้น, Grok ของ Max) อ่านก่อนคิดต่อ

- **กฎและเพดานในไฟล์นี้อ่านจากระบบที่รันจริงเมื่อ 2026-11-17** ไม่ใช่ชุดตัวอย่าง
- **Grok: ตอบเรื่องระบบจากไฟล์นี้ไฟล์เดียว** ห้ามตอบจากไฟล์อื่นใน repo (โดยเฉพาะ `ads-engine/rules.json` ซึ่งเป็นกฎชุดเก่าที่ไม่ได้ใช้) ถ้าคำตอบไม่มีในไฟล์นี้ ให้บอก Max ว่า "ไม่มีใน PK-brain" แล้วเปิดใบงานถามฝั่งเบ้น
- Grok มองไม่เห็นตัวเลขสดของร้าน (ยอดขาย ค่าแอด ออเดอร์ ผลของแอดแต่ละตัว) ต้องให้ Max เปิดจากหน้าเว็บ หรือเปิดใบงานถาม
- repo นี้เป็น public ห้ามใส่ token รหัสผ่าน หรือข้อมูลลูกค้าในโฟลเดอร์นี้
- วิธีเขียนบันทึกและเปิดใบงานอยู่ใน `grok-start.md`

## ถามตอบสั้น

**ระบบตัดสินแอดจากอะไร**
จาก ROAS ของแอดเทียบกับ "จุดคุ้มทุน" ของสินค้ารุ่นนั้น ไม่ใช่ ROAS ตายตัว และใช้ออเดอร์จริงจาก Page365 ไม่ใช่ตัวเลขของ Meta ระบบรันวันละ 2 รอบ เช้าและ 20:00

**จุดคุ้มทุนคืออะไร**
ROAS ที่ทำให้ขายแล้วเท่าทุนพอดีหลังหักต้นทุนสินค้าและค่าใช้จ่ายต่อออเดอร์ ยังไม่รวมค่าแอด รุ่นที่กำไรต่อชิ้นบางจะมีจุดคุ้มทุนสูง
ตัวอย่าง: ทั้งร้านราว 2.9 · รุ่น 121 ขาสั้นเอวยาง (โปร 3 ตัว 399) 5.75

**"1.4× คุ้มทุน" แปลว่าอะไร**
เอา 1.4 คูณจุดคุ้มทุนของรุ่นนั้น รุ่น 121: 1.4 × 5.75 = ROAS 8.05 · รุ่นที่คุ้มทุน 2.9: 1.4 × 2.9 = ROAS 4.06

**เปิดแอดใหม่แล้วเกิดอะไรขึ้น**
แอดที่เปิดอยู่และยังไม่มีขั้น ถูกใส่ขั้น "ทดลอง" ในรอบถัดไป แล้วเดินตามกฎ 4 ขั้นข้างล่าง

**ขายได้วันแรกเลย ระบบจะขึ้นงบทันทีไหม**
ไม่ ต้องขึ้นขั้น "ทดสอบระบบ" ก่อน คืออยู่ขั้นทดลองครบ 3 วัน, 3 วันล่าสุด ROAS ถึงจุดคุ้มทุน และมีออเดอร์จริง ≥ 3 ใบ จากนั้นถึงจะเข้ากฎขึ้นงบ

**แอดงบเล็ก (≤ 200/วัน) ขึ้นงบยังไง**
ในขั้นทดสอบระบบหรือทำเงิน: 7 วันล่าสุด ROAS ≥ 1.5× คุ้มทุน, ออเดอร์ ≥ 6 ใบ, ใช้เงินแล้ว ≥ 250 (ทำเงิน ≥ 300) → งบ ×2 แต่ไม่เกิน 300/วัน รอบละครั้งต่อ 24 ชม.
กฎขึ้นงบ +20% แบบปกติดู 3 วันและต้องใช้เงิน ≥ 450–600 ใน 3 วัน แอดงบ 50/วันจึงไม่เข้ากฎนั้น

**แอดจะโดนหยุดเมื่อไหร่**
ใช้เงินครบ 300 แล้วยังไม่มีออเดอร์เลย (ดูทั้ง 3 วันและ 7 วัน) → หยุด และในขั้นทดลอง: 7 วัน ROAS ต่ำกว่า 0.8× คุ้มทุน เมื่อใช้เงิน ≥ 700 → หยุด
การหยุดและการย้ายลงขั้น "ดับ" ทำเลยไม่ถามใน Discord (ตั้งแต่ 2026-11-12)

**ทำไมไม่เชื่อตัวเลข Meta**
Meta นับเกินจริง (11–13 ต.ค. Meta 268 ออเดอร์ / Page365 235 · 26 ต.ค. Meta 257 / จริง 109) วันที่ยังไม่มีไฟล์ Page365 ถึงจะใช้ตัวเลข Meta

**จะเปิดแอดรุ่นใหม่ ต้องเตรียมอะไร**
ให้ระบบรู้จักรุ่นนั้นก่อน: มีทุนในแคตตาล็อก, มี "สายสินค้า" ในหน้า สินค้า/ต้นทุน พร้อมราคาโปร และชื่อแคมเปญมีคำค้นของสายสินค้านั้น ถ้าไม่มี ระบบจะใช้จุดคุ้มทุนของทั้งร้าน (≈ 2.9) ซึ่งทำให้แอดที่ขาดทุนดูเหมือนกำไร
ให้เปิดใบงานขอเพิ่มสายสินค้าก่อนเผยแพร่แอดรุ่นใหม่

## กฎ 4 ขั้น (ชุดที่รันจริง)

"ใช้ ≥" คือยอดใช้เงินขั้นต่ำในช่วงที่ดูก่อนกฎจะทำงาน · "×" คือจำนวนเท่าของจุดคุ้มทุน · "เว้น" คือเวลาที่ต้องรอก่อนกฎเดิมทำซ้ำ

### ขั้น 1 ทดลอง

| เมื่อ | ระบบทำ |
|---|---|
| 3 วัน: 0 ออเดอร์ ใช้ ≥ 300 | หยุด |
| 7 วัน: 0 ออเดอร์ ใช้ ≥ 300 | หยุด |
| 7 วัน: ROAS < 0.8× ใช้ ≥ 700 | หยุด |
| 3 วัน: ROAS ≥ 1× และ ≥ 3 ออเดอร์ อยู่ขั้นนี้ ≥ 3 วัน | ย้ายขึ้น ทดสอบระบบ |

### ขั้น 2 ทดสอบระบบ

| เมื่อ | ระบบทำ |
|---|---|
| งบ ≤ 200 · 7 วัน: ROAS ≥ 1.5× · ≥ 6 ออเดอร์ · ใช้ ≥ 250 | งบ ×2 ไม่เกิน 300 (เว้น 24 ชม.) |
| 3 วัน: ROAS ≥ 1.6× · ≥ 5 ออเดอร์ · ใช้ ≥ 450 | +20% (เว้น 11 ชม.) |
| 3 วัน: ROAS ≥ 1.4× · ≥ 5 ออเดอร์ · ใช้ ≥ 600 | +20% (เว้น 72 ชม.) |
| 3 วัน: ROAS < 1× ใช้ ≥ 450 | −20% (เว้น 48 ชม.) |
| 3 วัน: ROAS < 0.8× ใช้ ≥ 750 | −20% (เว้น 24 ชม.) |
| 3 วัน หรือ 7 วัน: 0 ออเดอร์ ใช้ ≥ 300 | หยุด |
| 7 วัน: ROAS ≥ 1.4× และ ≥ 10 ออเดอร์ อยู่ขั้นนี้ ≥ 5 วัน | ย้ายขึ้น ทำเงิน |
| 3 วัน: ROAS < 0.5× ใช้ ≥ 750 | ย้ายลง ดับ |
| 7 วัน: ROAS < 1× ใช้ ≥ 1,000 อยู่ขั้นนี้ ≥ 7 วัน | ย้ายลง ดับ |
| 7 วัน: ROAS < 0.8× ใช้ ≥ 700 อยู่ขั้นนี้ ≥ 3 วัน | ย้ายลง ดับ |

### ขั้น 3 ทำเงิน

| เมื่อ | ระบบทำ |
|---|---|
| 3 วัน: ROAS ≥ 1.5× · ≥ 6 ออเดอร์ · ใช้ ≥ 600 | +20% (เว้น 11 ชม.) |
| 3 วัน: ROAS ≥ 1.4× · ≥ 8 ออเดอร์ · ใช้ ≥ 1,000 | +20% (เว้น 72 ชม.) |
| งบ ≤ 200 · 7 วัน: ROAS ≥ 1.5× · ≥ 6 ออเดอร์ · ใช้ ≥ 300 | งบ ×2 ไม่เกิน 300 (เว้น 24 ชม.) |
| 3 วัน: ROAS < 1.1× ใช้ ≥ 450 | −20% (เว้น 48 ชม.) |
| 3 วัน: ROAS < 0.8× ใช้ ≥ 750 | −20% (เว้น 24 ชม.) |
| 7 วัน: คนเห็นซ้ำเฉลี่ย > 3 ครั้ง | แจ้งให้เปลี่ยนครีเอทีฟ ไม่ขยับงบ |
| 7 วัน: 0 ออเดอร์ ใช้ ≥ 300 | หยุด |
| 3 วัน: ROAS < 0.5× ใช้ ≥ 750 | ย้ายลง ดับ |
| 7 วัน: ROAS < 1× ใช้ ≥ 1,000 อยู่ขั้นนี้ ≥ 7 วัน | ย้ายลง ดับ |
| 7 วัน: ROAS < 0.8× ใช้ ≥ 700 อยู่ขั้นนี้ ≥ 3 วัน | ย้ายลง ดับ |

### ขั้น 4 ดับ → ทดสอบใหม่

| เมื่อ | ระบบทำ |
|---|---|
| 3 วัน: ROAS < 1× ใช้ ≥ 450 | −20% (เว้น 48 ชม.) |
| 3 วัน หรือ 7 วัน: 0 ออเดอร์ ใช้ ≥ 300 | หยุด |
| 7 วัน: ROAS < 1× ใช้ ≥ 700 | หยุด แล้วทำแอดใหม่แทน |
| 7 วัน: ROAS ≥ 1.2× และ ≥ 5 ออเดอร์ อยู่ขั้นนี้ ≥ 5 วัน | กลับขึ้น ทำเงิน |

## เพดานและตัวกัน (ค่าที่ตั้งจริง 2026-11-17)

- ขยับงบได้ไม่เกิน 20% ต่อรอบ (ยกเว้นกฎตัวชนะงบเล็กที่ ×2 ไม่เกิน 300)
- งบต่อแคมเปญ 50–3,200/วัน ตัวชนะที่พิสูจน์แล้ว (ขั้นทำเงิน, 7 วัน ROAS จริง ≥ 1.5× คุ้มทุน, ≥ 10 ออเดอร์) ขึ้นได้ถึง 5,000
- งบรวมทุกแคมเปญ 28,800/วัน เพดานนี้กั้นเฉพาะการขึ้นงบ การลดงบผ่านเสมอ
- แคมเปญเดียวกันขึ้นงบได้ครั้งเดียวต่อ 48 ชม. (งบต่ำกว่า 500 ขึ้นได้ทุกรอบ)
- จุดคุ้มทุนของแคมเปญ: ใช้ออเดอร์จริงของแคมเปญนั้นเมื่อมี ≥ 15 ใบใน 14 วัน ถ้ายังไม่ถึง ใช้ของสายสินค้า แล้วจึงคิดจากราคาโปรต่อตัวที่ต่ำที่สุดกับทุนในแคตตาล็อก ไม่มีสายสินค้าเลยใช้ของทั้งร้าน
- ทุกวันจันทร์: ถ้า MER จริง 7 วัน ≥ 3.86 ระบบเสนอขึ้นเพดานงบรวม +20% ใน Discord มีผลเมื่อมีคนกดอนุมัติ
- แคมเปญขั้นทำเงินที่ชนเพดานและยังดี: ระบบเสนอคัดลอกแคมเปญใน Discord มีผลเมื่อมีคนกดอนุมัติ

## เป้าและหลักคิด

- **เป้า:** กำไรสุทธิ 200,000 บาท/เดือน (ตั้ง 2026-11-03) = ยอดขาย − ต้นทุนสินค้า − ค่าใช้จ่ายต่อออเดอร์ − ค่าแอด ไม่รวมต้นทุนคงที่ ต้องได้ยอดขายราว 67,000/วัน ใช้แอดราว 17,300/วัน ที่ MER 3.86
- **ต้นทุนมีชุดเดียว:** ทุนดิบจากแคตตาล็อก บวกค่าใช้จ่ายต่อออเดอร์: COD 1% (เฉพาะออเดอร์ COD ซึ่งเป็นราว 92% ของร้าน) · ตีกลับ/เสีย/หาย 1% · ค่าส่ง 15 · VAT 7% (คิดหลังหักค่าส่ง) · ถุง 1 ค่าเก็บเงินปลายทาง +50 นับเป็นรายได้
- **นับกำไรเป็นรายชิ้น:** แอดเดียวขายหลายโปร จึงคิดต้นทุนตามจำนวนชิ้นจริงของออเดอร์
- **ต้องใช้เงินถึงเกณฑ์ก่อนถึงจะตัด:** ไม่ตัดแอดที่ยังใช้เงินไม่พอจะรู้ผล
- **ไม่มี AI ในรอบตัดสินใจรายวัน:** กฎเป็น if/then ล้วน AI ใช้คิดกฎ ตรวจ และเขียนแคปชัน
- **ของที่เขียนออกนอกระบบเปิดตัวแบบปิดไว้ก่อน:** ลองแบบไม่แตะของจริงให้เบ้นดู แล้วเบ้นเปิดเอง

## ใครอนุมัติอะไร (เบ้น 2026-11-17)

เบ้น: "ทำได้หมดทุกอย่าง Full loop ยกเว้นอันที่เป็นปัญหากับ System หลัก"

- **Max อนุมัติเองได้:** วงทำแอดทั้งวง ตั้งแต่บรีฟ รูป แคปชัน โปร ตั้งแอด เผยแพร่ ทั้งผ่านเว็บและใน Ads Manager
- **ต้องให้เบ้นตัดสิน** (เบ้นยืนยันรายการนี้ 2026-11-17):
  - แก้กฎ 4 ขั้น เกณฑ์ เพดานงบ หรือสวิตช์ในหน้า Settings
  - แก้โค้ด หรือ deploy ระบบ
  - ทำให้ระบบหลักอ่านตัวเลขผิด เช่น ยิง purchase ทดสอบเข้า Meta หรือแก้ข้อมูลออเดอร์
- Max หรือ Grok อยากเปลี่ยนสิ่งที่อยู่ในรายการข้างบน ให้เปิดใบงาน (วิธีอยู่ใน `grok-start.md`): Grok ขอ → เบ้นตัดสิน → Claude ทำ → Max ตรวจ → ผลถูกเขียนกลับเข้าไฟล์นี้

## วงครีเอทีฟและแอดทดสอบ "(Grok)"

- **ห้องฝึก** (หน้า `/studio`): ทีมอัปโหลดรูปสินค้าและตัวอย่างแคปชัน Claude เขียนแคปชัน รูปทำใน ChatGPT จาก prompt ของห้อง
- **Playbook แคปชัน:** ฉบับร่างใหม่ต้องชนะฉบับที่ใช้อยู่ ≥ 55% จาก 20 คู่ ที่กรรมการ AI ตัดสินแบบไม่รู้ว่าฝั่งไหนเป็นของใคร ถึงจะถูกใช้
- **จากห้องสู่แอดจริง:** ชุดโพสต์ที่ผ่านถูกเสนอใน Discord #studio-training Max กด ✅ → เปิดแคมเปญทดสอบชื่อลงท้าย "(Grok)"
- **แคมเปญที่สร้างเองใน Ads Manager** ชื่อขึ้นต้น "Grok" หรือลงท้าย "(Grok)" จะขึ้นการ์ดผลทดสอบบน `/studio` ด้วย แคมเปญชื่ออื่นยังถูกกฎ 4 ขั้นดูแลเหมือนกัน แต่ไม่ขึ้นการ์ดนั้น
- **"งานวันนี้ของ Grok"** บน `/studio`: เว็บคิดย้อนจากช่องว่างของเป้า → ต้องมีตัวชนะกี่ตัว → ต้องทดสอบกี่ตัว → วันนี้ต้องทำรูปกี่รูป สินค้าไหน ราว 70% ต่อยอดตัวที่ขายได้โดยเปลี่ยนตัวแปรเดียวต่อรูป ที่เหลือลองสินค้าที่ยังไม่มีรูป
- **โปรและจุดขายมาจากโน้ตของ Max เท่านั้น** ระบบไม่แต่งโปรเอง

## จุดอ่อนที่รู้อยู่

- กรรมการ AI ตัดสินแคปชันที่ AI เขียน อาจชอบสิ่งที่อ่านแล้วดี ไม่ใช่สิ่งที่ขายได้ ตัววัดจริงคือ ROAS ของแอด
- ยังไม่มีสรุปอัตโนมัติว่าตัวแปรไหน (โปร 3 ตัว, ด้านหลัง ฯลฯ) ชนะหรือแพ้กี่ครั้ง
- ชื่อแคมเปญไม่ได้บอกว่าขายรุ่นไหนจริง ลูกค้าจากโพสต์เดียวซื้อหลายรุ่น และบางแคมเปญส่งรุ่นทดแทน
- ไฟล์นี้ไม่อัปเดตเองเมื่อกฎในระบบเปลี่ยน ต้องมีคนแก้ตาม วันที่ด้านบนบอกว่าตรงกับระบบล่าสุดเมื่อไหร่
