# ตารางแนะนำไซส์ (ยีนส์ชาย ทรงกระบอกเล็ก / ผ้ายืด)

| ไซส์ | เอว (นิ้ว) | น้ำหนักโดยประมาณ (กก.) |
|---|---|---|
| 28 | 28-29 | 45-52 |
| 30 | 30-31 | 52-60 |
| 32 | 32-33 | 60-68 |
| 34 | 34-35 | 68-76 |
| 36 | 36-37 | 76-84 |
| 38 | 38-39 | 84-92 |
| 40 | 40-41 | 92-100 |
| 42 | 42-43 | 100-108 |
| 44 | 44-45 | 108-116 |

- ผ้ายืด: ถ้าชอบหลวมให้ +1 ไซส์
- ไซส์ขายดี (core sizes) ของเพจ: 30, 32, 34 ห้ามหมดก่อนยิงแอด
- FREESIZE (สปอร์ต) ใส่ได้เอว 28-36
